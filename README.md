# e-plantShopping

**Paradise Nursery** is a React-based shopping cart application for an online plant shop that offers a variety of house plants.

## Features
- Landing page with company information and a "Get Started" button
- Product listing page with plants grouped into categories
- Add to Cart functionality using Redux state management
- Shopping cart page with quantity controls, item removal, and total cost calculation
- Dynamic cart item count displayed in the navbar

## Tech Stack
- React
- Redux Toolkit
- Vite
